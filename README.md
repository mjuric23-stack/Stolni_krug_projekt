# Stolni_krug_projekt
Ovaj projekt omogućuje jednostavan pregled nižih i viših stopa poreza na dohodak te broja nezaposlenih prema odabranoj županiji, gradu ili općini. Korisnik odabire željenu lokaciju putem padajućih izbornika, a podaci se prikazuju na jednom mjestu. Projekt je izrađen pomoću HTML-a, CSS-a i JavaScripta, uz mogućnost ugradnje u Google Sites.
Stranica: https://sites.google.com/view/pregledporezagradovaiopcina/home
Popis podataka: https://porezna-uprava.gov.hr/hr/porez-na-dohodak-3939/3939 ; https://statistika.hzz.hr/Statistika.aspx?tipIzvjestaja=1
